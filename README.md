# Transport Catalogue — Маршрутизатор общественного транспорта

Система хранения и обработки геоданных общественного транспорта с функцией построения оптимальных маршрутов (поиск кратчайшего пути по времени с учетом пересадок), рендерингом векторных карт и бинарной сериализацией базы данных.

## 🛠 Технологический стек
* **Язык:** C++17
* **Библиотеки:** STL, Google Protobuf (бинарная сериализация)
* **Форматы данных:** JSON (входные запросы и ответы), SVG (визуализация карт)
* **Сборка:** CMake

## ✨ Ключевые возможности
* **Оптимизированное хранение данных:** быстрая индексация остановок и автобусных маршрутов за $O(1)$ с использованием хэш-таблиц и `std::string_view` для исключения лишних копирований строк в памяти.
* **Построение маршрутов на графах:** расчет оптимального пути между остановками с помощью взвешенного ориентированного графа и алгоритма Дейкстры с учетом времени ожидания транспорта и длительности поездок.
* **Визуализация карты (SVG):** генерация векторной карты маршрутов с автоматическим масштабированием географических координат (сферическая проекция) и отрисовкой остановок и подписей.
* **Разделение на процессы (Serialization):** приложение разделено на два независимых режима:
  1. `make_base` — парсинг исходных данных, построение графа и сохранение в компактный бинарный файл через **Google Protobuf**.
  2. `process_requests` — мгновенная загрузка готовой базы и обработка потоковых запросов на поиск маршрутов и рендеринг карт.

## 🚀 Сборка и запуск

```bash
git clone https://github.com
cd transport_catalogue
mkdir build && cd build

cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j\$(nproc)
```

### Пример использования
1. Формирование сериализованной базы данных:
```bash
./transport_catalogue make_base < make_base_config.json
```
2. Обработка запросов на поиск маршрута и получение карты:
```bash
./transport_catalogue process_requests < process_requests.json > output.json
```
