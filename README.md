# Transport Catalogue — Справочник и маршрутизатор общественного транспорта

Система на C++17 для работы с геоданными: хранение каталога остановок и автобусных маршрутов, расчет оптимальных поездок с учетом пересадок и генерация SVG-карт.

## 🛠 Технологический стек
* **Язык:** C++17
* **Сборка:** CMake
* **Форматы ввода/вывода:** JSON, SVG

## 📂 Архитектура проекта
* `domain/` — структуры данных предметной области.
* `json/` — модуль парсинга и формирования JSON-документов.
* `svg/` — графический движок для отрисовки векторных карт.
* `transport_catalogue.*` — базовый каталог для хранения и быстрого поиска остановок и маршрутов.
* `transport_router.*` — подсистема построения маршрутов с использованием взвешенных графов.
* `main.cpp` — связующее звено логики и ввода-вывода.

## 🚀 Сборка и запуск

```bash
git clone https://github.com
cd transport_catalogue
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build .
```

### Пример использования
```bash
./transport_catalogue < input.json > output.json
```
*(Актуальное имя исполняемого файла сверьте с настройками `add_executable` в вашем `CMakeLists.txt`).*
